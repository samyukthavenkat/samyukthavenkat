## Publication standards

Before a project is made public:

- Confirm ownership or permission to publish every source file and dataset.
- Remove credentials, API keys, personal data, employer data and confidential commercial information.
- Include a clear problem statement, methods, setup instructions and limitations.
- Make every reported metric traceable to code, data or a cited source.
- Label simulated, illustrative and synthetic results accurately.
- Do not claim that a planned or partially implemented pipeline is complete.
